# B-01. LLM protocol and the cassette provider

**Phase:** B | **Depends on:** A-02 | **Read:** `docs/CONTRACTS.md` and `history/plan/components/13-llm-client.md sections 1, 4`

Load **only** those two documents plus this file. Do not read the rest of `history/plan/`.

---

## Build

`LLMClient` protocol, `LLMUsage`, `Prompt`, and the cassette provider.

**Cassettes are already authored and committed** under `tests/fixtures/llm_cassettes/`, keyed on
`(prompt_id, scenario)`. You do not create them. Resolution order:

1. `<prompt_id>/<scenario>.json`, where scenario comes from `WHA_SCENARIO`
2. `<prompt_id>/default.json`
3. **Hard failure** naming the prompt id, the scenario and the path looked for

`investigate/*.json` holds a **list** consumed in order; running past the end yields `Done`, which
terminates the loop cleanly rather than raising.

---

## Tests

Write these first, then make them pass.

- `test_cassette_provider_is_default` -- unset config gives `cassette`
- `test_cassette_miss_fails_loudly` -- names prompt id, scenario and path
- `test_scenario_cassette_preferred_over_default`
- `test_default_used_when_no_scenario_file`
- `test_investigate_list_consumed_in_order`
- `test_investigate_past_end_yields_done`
- `test_cassette_never_reaches_network`
- `test_authored_origin_recorded_in_audit` -- `model_id` is `authored-fixture`, not a real model

```bash
uv run pytest tests/unit/llm/test_cassette.py -q
```

Plus: `uv run pytest` green **in full**, `uv run ruff check src tests` clean, no test weakened, no
contract changed.

## Do not

- Build the cassette provider **before** any live provider. A live provider written first invites
  tests that quietly hit the network.
- **Do not author, edit or regenerate a cassette.** They are committed fixtures. If one is missing
  for a scenario you need, that is a blocker.
