# A-03. Database schema and connections

**Phase:** A | **Depends on:** A-02 | **Read:** `docs/CONTRACTS.md` and `history/plan/components/02-storage.md`

Load **only** those two documents plus this file. Do not read the rest of `history/plan/`.

---

## Build

`src/wha/db/schema.sql` copied verbatim from the contract. `connect()` with all four pragmas,
`transaction()` context manager, `apply_schema()` idempotent, `to_iso`/`from_iso`.

---

## Tests

Write these first, then make them pass.

- `test_apply_schema_is_idempotent`
- `test_foreign_keys_are_enforced` -- **fails if the pragma is missing, which is the point**
- `test_transaction_rolls_back_on_error`
- `test_transaction_commits_on_success`
- `test_to_iso_rejects_naive_datetime`
- `test_from_iso_returns_aware_utc`

---

## Exit

```bash
uv run pytest tests/unit/db -q
```

Plus: `uv run pytest` green **in full**, `uv run ruff check src tests` clean, no test weakened, no
contract changed.

---

## Do not

- Do not build migration machinery. One `apply_schema` is the whole requirement.
- Do not import sqlite3 anywhere outside `src/wha/db/`.
