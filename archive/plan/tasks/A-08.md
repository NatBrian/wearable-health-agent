# A-08. Store raw and normalise

**Phase:** A | **Depends on:** A-03, A-05 | **Read:** `docs/CONTRACTS.md` and `history/plan/components/01-data-ingestion.md section 3`

Load **only** those two documents plus this file. Do not read the rest of `history/plan/`.

---

## Build

`store_raw()` writes verbatim with sha256, `INSERT OR IGNORE` on duplicate. Then
`normalise_and_store()` upserts the typed rows. **Raw is stored before normalisation, always.**

---

## Tests

Write these first, then make them pass.

- `test_raw_stored_before_normalise` -- a normalisation failure still leaves the raw row
- `test_raw_payload_duplicate_is_ignored` -- one row, no exception
- `test_overlapping_windows_upsert`

uv run pytest tests/unit/ingest -q

contract changed.

## Do not

- Do not normalise before storing raw.
