# Forecasting: the model that was deleted

**An engineering decision, recorded so it is not made again by accident.**

A neural forecaster was built to predict a night's resting heart rate, so the system could
compare a night against a prediction rather than against a plain median. It was compared
against that median on our own data and separated illness less well, so it was removed
along with everything that fed it.

Kept here because deleting work without recording why invites somebody to rebuild it.
Nothing in this folder is a claim about health.
