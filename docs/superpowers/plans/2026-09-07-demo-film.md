- Always `uv run`. Bare `python` resolves to another project's venv.
- **Never write to subject `me`.** The live database is opened read-only, once.
- The parked `sim` episode `ep_20445aee7610` must survive untouched.
- No em-dashes and no en-dashes in any caption, card, commit message or document.
- UI copy may contain no digits. The dashboard may not import from `wha.service`.
- `docs/CONTRACTS.md` is compared against the code on every test run.
- Targeted tests while working, `uv run pytest -n auto` once at the end.
- Never weaken a test to make it pass.
- **If the timeline produces something unexpected, stop and investigate the cause.** Write
  down the prediction for each day before running it. Fix defects, do not film around them.
