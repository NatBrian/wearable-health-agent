# C-09. serve and the scheduler

**Phase:** C | **Depends on:** C-01, B-20 | **Read:** `docs/CONTRACTS.md` and `history/plan/components/17-cli-and-runtime.md sections 4-5`

---

## Build

`wha serve` with the APScheduler thread. Four jobs, `max_instances=1`, `coalesce=True`, a shared
lock. A raising job writes a status row and never kills the thread. Document the Task Scheduler
entry.
