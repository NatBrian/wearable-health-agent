## Build

Typer app with global `--subject`, `--db`, `-v`, `--json`. Meaningful exit codes 0, 1, 2, 3.
`doctor` checks everything independently and never prints a secret. `nightly` is idempotent and
refuses rather than guessing when data is stale.

**Also two commands that Phase A's exit condition depends on:**

- `wha demo run <scenario> --dry-run` -- generate the synthetic scenario, run the deterministic
  batch over it, print a night-by-night table. **No episode, no agent, no LLM.** B-24 later extends
  the same command to run a full episode without `--dry-run`.
- `wha belief explain --subject S --nights A:B` -- compute the belief over a night range and print
  the marginals per night with the trigger for each update. **Works without an episode**, because
  no episode exists in Phase A. B-24 later adds the `--episode` form.
