## Build

Create `pyproject.toml` with the exact dependency groups from the contract, `.python-version`
pinned to 3.12, `ruff.toml` with line length 100, `.env.example` documenting every key with
placeholder values, and the empty package tree under `src/wha/` from `01-overview.md` section 9.

**Register the console script**, or every later task's exit command fails:

```toml
[project.scripts]
wha = "wha.cli:app"
```

Create `src/wha/cli.py` with a bare Typer app so the entry point resolves from task one. Create the `tests/` tree with `tests/unit/`, `tests/integration/`, `tests/scenario/`, `tests/ui/`,
and a `tests/conftest.py` containing:

```python
@pytest.fixture(autouse=True, scope="session")
def _force_cassette_provider(monkeypatch_session):
    monkeypatch_session.setenv("WHA_LLM_PROVIDER", "cassette")
```

**Autouse and session-scoped, overriding `.env`.** `.env` configures a live provider for development,
and without this fixture the suite would hit a real API hundreds of times across an unattended run:
slow, costly, and nondeterministic enough to break every frozen scenario assertion. Plus a temporary
database fixture.

Run `uv lock` and commit `uv.lock`.
